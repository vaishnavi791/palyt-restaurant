# Palyt Kitchen & Menu Manager

A lightweight inventory and menu management tool built for Palyt that syncs kitchen stock levels with diner menu availability in real time.

## How to Open the App
1. Clone or download this repository.
2. Double-click **`index.html`** or open it in browser.

## How to Run Tests
To run the automated logic tests:
1. Open your terminal in the project folder.
2. Run the following command (requires Node.js):
   ```bash
   node test.js
